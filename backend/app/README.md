# Backend App

Εδώ βρίσκεται ο πυρήνας της εφαρμογής FastAPI. Ο διαχωρισμός του κώδικα σε αρχεία γίνεται για καλύτερη οργάνωση και ευκολότερη συντήρηση.

## Αρχεία σε αυτόν τον φάκελο:
- `main.py`: Το αρχείο εισόδου της εφαρμογής (entry point). Εδώ αρχικοποιείται το FastAPI (`app = FastAPI()`), προστίθεται το CORS (ώστε να επιτρέπει αιτήματα από το frontend) και γίνονται register (include) όλα τα `routes` (endpoints).
- `config.py`: Διαχειρίζεται τις ρυθμίσεις της εφαρμογής. Διαβάζει τα environment variables (από το `.env`) και τα κάνει διαθέσιμα στον υπόλοιπο κώδικα μέσω της κλάσης `Settings` (Pydantic).
- `db.py`: Φροντίζει για τη σύνδεση με το Supabase (Βάση Δεδομένων). Αρχικοποιεί τον Supabase client χρησιμοποιώντας τα URL και Service Role Key που βρίσκονται στο `config.py`.
- `azure_agent.py`: Περιέχει τη λογική επικοινωνίας με το Azure AI Foundry. Διαθέτει τη συνάρτηση `call_agent` η οποία φτιάχνει ένα νέο thread, στέλνει το μήνυμα του χρήστη στον AI Agent, τρέχει τον agent, και επιστρέφει την απάντηση.
- `models.py`: Ορίζει τη δομή των δεδομένων (Data Validation Models) με τη βοήθεια του Pydantic. Περιέχει μοντέλα όπως `ChatRequest` ή `ItemCreate`, που εξασφαλίζουν ότι το JSON που λαμβάνει ή στέλνει το API έχει τη σωστή μορφή.
- `routes/`: Φάκελος που περιέχει τα διάφορα endpoints (διαδρομές) του API, σπασμένα σε θεματικές κατηγορίες.
- `README.md`: Αυτό το αρχείο.
