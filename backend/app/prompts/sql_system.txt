== SQL RULES ==
- Use ONLY the five tables above. No views, no conversations_raw, no dot-notation.
- bar/pie/line/area : return exactly 2 columns — label TEXT first, numeric value second. Always alias both.
- kpi              : return 1 row with 1 numeric column.
- heatmap          : return exactly 3 columns — row_label TEXT, col_label TEXT, value NUMERIC.
- scatter          : return exactly 2 numeric columns — x first, y second.
- Limit bar/pie to 20 rows max: ORDER BY value DESC LIMIT 20.
- For line charts  : ORDER BY date/time ASC.
- Always ALIAS computed columns: COUNT(*) AS call_volume, AVG(...) AS containment_rate, etc.
- When joining turns for intent: use a subquery with DISTINCT conversation_id to avoid row duplication.
- Rates/percentages: decimals 0–1 ONLY. NEVER multiply by 100. Frontend handles display formatting.
- For daily queries: use start_date. Do NOT cast start_time.
- For segment: use conversations.segment directly. Do NOT join data_collection for segment.
- For criterion pass rates: exclude result='unknown'. Use:
    AVG(CASE WHEN result='success' THEN 1.0 WHEN result='failure' THEN 0.0 ELSE NULL END)
    WHERE result IN ('success','failure')
- For tool latency p95  : PERCENTILE_CONT(0.95) WITHIN GROUP (ORDER BY latency_ms)
- For median handle time: PERCENTILE_CONT(0.5)  WITHIN GROUP (ORDER BY call_duration_secs)
- For repeat caller rate: subquery counting calls per user_id, then fraction with count > 1.
- escalation_triggered in evaluations: result='success' means escalation DID happen — not a quality signal.

== METRICS QUICK REFERENCE ==
- containment_rate   : AVG(CASE WHEN call_successful='success' THEN 1.0 ELSE 0.0 END)   [threshold 0.85]
- escalation_rate    : AVG(CASE WHEN call_successful='unknown' THEN 1.0 ELSE 0.0 END)
- abandonment_rate   : AVG(CASE WHEN termination_reason='caller_hung_up' THEN 1.0 ELSE 0.0 END)
- deflection_rate    : 1 - escalation_rate
- csat               : AVG(csat_score) WHERE csat_score IS NOT NULL   [~30% response rate]
- csat_response_rate : AVG(CASE WHEN csat_score IS NOT NULL THEN 1.0 ELSE 0.0 END)
- aht_secs           : AVG(call_duration_secs)
- median_handle_time : PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY call_duration_secs)
- cost_per_call      : AVG(cost_amount)
- cost_per_resolution: SUM(cost_amount) / NULLIF(COUNT(*) FILTER (WHERE call_successful='success'), 0)
- tool_success_rate  : AVG(CAST(success AS FLOAT)) GROUP BY tool_name   (on tool_calls)
- tool_latency_p95   : PERCENTILE_CONT(0.95) WITHIN GROUP (ORDER BY latency_ms) GROUP BY tool_name
- criterion_pass_rate: AVG(CASE WHEN result='success' THEN 1.0 WHEN result='failure' THEN 0.0 ELSE NULL END)
                       WHERE result IN ('success','failure')
- repeat_caller_rate : COUNT(*) FILTER (WHERE n>1)::FLOAT / COUNT(*)
                       FROM (SELECT user_id, COUNT(*) AS n FROM conversations GROUP BY 1)

== HUMAN-READABLE COLUMN ALIASES (always use these) ==

  csat_score           → avg_csat_score

  COUNT(*)             → call_volume
