# API Routes

Αυτός ο φάκελος περιέχει όλες τις διαδρομές (endpoints) του FastAPI.

## Αρχεία σε αυτόν τον φάκελο:
- `health.py`: Περιέχει το endpoint `GET /health` το οποίο επιστρέφει `{"status": "ok"}`. Είναι χρήσιμο για να ελέγχουμε αν ο διακομιστής (server) τρέχει σωστά.
- `items.py`: Περιέχει τα endpoints (`GET /api/items` και `POST /api/items`) για τη διαχείριση απλών εγγραφών στη βάση του Supabase. Αυτό προστέθηκε ως παράδειγμα CRUD λειτουργικότητας.
- `chat.py`: Περιέχει το κεντρικό endpoint `POST /api/chat`. Παίρνει το μήνυμα του χρήστη, το αποθηκεύει στο Supabase, καλεί τη συνάρτηση `call_agent` από το `azure_agent.py` για να πάρει την απάντηση της τεχνητής νοημοσύνης, την αποθηκεύει και αυτή, και την επιστρέφει στο frontend.
- `README.md`: Αυτό το αρχείο.
