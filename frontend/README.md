# Frontend

Αυτός ο φάκελος περιέχει την πλευρά του πελάτη (client-side) της εφαρμογής, χτισμένη με Next.js 15, React, και Tailwind CSS.

## Αρχεία σε αυτόν τον φάκελο:
- `.env.example`: Πρότυπο αρχείο περιβαλλοντικών μεταβλητών. Περιέχει το `NEXT_PUBLIC_API_URL` που χρειάζεται η εφαρμογή για να επικοινωνήσει με το backend.
- `package.json` & `package-lock.json`: Αρχεία διαχείρισης πακέτων του npm. Περιέχουν τις εξαρτήσεις (dependencies) του frontend.
- `tsconfig.json`: Ρυθμίσεις του TypeScript.
- `next.config.ts`: Αρχείο ρυθμίσεων του Next.js.
- `eslint.config.mjs`: Ρυθμίσεις για το ESLint.
- `README.md`: Το παρόν αρχείο που εξηγεί τον σκοπό του φακέλου.
