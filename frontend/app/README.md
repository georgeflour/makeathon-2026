# App Router

Αυτός ο φάκελος χρησιμοποιεί το σύστημα δρομολόγησης (App Router) του Next.js. Κάθε αρχείο εδώ καθορίζει τη δομή και το στυλ των σελίδων.

## Αρχεία σε αυτόν τον φάκελο:
- `layout.tsx`: Είναι το κεντρικό layout (σκελετός) όλης της εφαρμογής. Περιλαμβάνει το `<Navbar />` και το `<Footer />` ώστε να εμφανίζονται σε κάθε σελίδα, και καθορίζει το γενικό HTML `<body>` και τα γραμματοσειρές.
- `page.tsx`: Η αρχική (home) σελίδα της εφαρμογής. Εμφανίζει το κεντρικό κείμενο (Hero section) και το συστατικό `<ChatBox />`.
- `globals.css`: Το κεντρικό αρχείο CSS που περιέχει τις μεταβλητές χρωμάτων (color tokens) και τις βασικές ρυθμίσεις του Tailwind CSS (π.χ. υποστήριξη για Dark Mode).
- `README.md`: Αυτό το αρχείο.
