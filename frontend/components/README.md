# Components

Σε αυτόν τον φάκελο αποθηκεύονται τα επαναχρησιμοποιήσιμα δομικά στοιχεία (React Components) του UI.

## Αρχεία σε αυτόν τον φάκελο:
- `Navbar.tsx`: Η πάνω μπάρα πλοήγησης της εφαρμογής. Δείχνει το λογότυπο και κάποια links.
- `Footer.tsx`: Το κάτω τμήμα (υποσέλιδο) της σελίδας με πληροφορίες πνευματικών δικαιωμάτων.
- `ChatBox.tsx`: Το κεντρικό συστατικό ανταλλαγής μηνυμάτων. Αναλαμβάνει να πάρει την είσοδο του χρήστη, να καλέσει το API του backend (`/api/chat`) μέσω της συνάρτησης `sendChatMessage`, και να εμφανίσει την απάντηση του AI Agent. Διαχειρίζεται το UI φόρτωσης (loading state) και τυχόν σφάλματα.
- `README.md`: Αυτό το αρχείο.
