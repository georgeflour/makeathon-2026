# Lib

Αυτός ο φάκελος περιέχει βοηθητικές συναρτήσεις (utilities / helpers) που δεν ανήκουν άμεσα στο UI, αλλά προσφέρουν λειτουργικότητα στην εφαρμογή.

## Αρχεία σε αυτόν τον φάκελο:
- `api.ts`: Περιέχει συναρτήσεις που αναλαμβάνουν την επικοινωνία (HTTP Requests) με το backend.
  - Η συνάρτηση `sendChatMessage` στέλνει το μήνυμα του χρήστη στο `/api/chat`.
  - Η συνάρτηση `getHealth` ελέγχει αν ο server τρέχει μέσω του `/health`.
- `README.md`: Αυτό το αρχείο.
